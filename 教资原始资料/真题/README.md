本目录现为 1,409 个文件（1,390 CSV + 13 README.md〔含 4 份本次新建的答案目录 README〕+ 6 个 `真题/.mimosa/` 工具状态 JSON）是 `数据集/教资/` 14,500 题的原件层。题库 `source.files[].path` 全部以写死前缀 `教资/真题/` 引用这里的 CSV——`教资` 是仓库根指向 `教资原始资料` 的符号链接，`build_kb.py` 的 `SRC = ROOT/'教资'/'真题'` 与 `审查/validate_kb.py` 的 Q_SOURCE_UNRESOLVED 存在性检查都依赖该链接；写文件只用真实目录名 `教资原始资料/真题/…`。原始 CSV 本身不进检索库：入库的是结构化后的题/材料/卡片，CSV 只用于答案与题面的逐题溯源。

## 编码与结构（逐目录抽读文件头确认）

- 全部 1,390 份 CSV：UTF-8、无 BOM。真题卷含 CRLF 换行（现算换行总数：初中 8,066、高中 6,478、小学 1,374、幼儿 612），4 个答案目录 1,390 份答案卷逐字节检查全部 0 换行、单行到底。
- 题与题的分隔是行首"数字、"（U+3001 顿号），不是 CSV 逗号；答案卷形如 `1、B2、A3、D…`，主观题一律"参见解析"占位（这正是主库大量题 `参见解析` 缺口的源头，官方评分参考未取得；现算：每个答案目录各有 6 份"整卷所有题号都只写参见解析"的答案卷）。
- 答案文件名 = 题文件名 + "（答案）.csv"（个别变体在"（答案）"前多一个空格，初中真题答案 8 份、高中真题答案 6 份）；`build_kb.py` 第 452 行按这两种后缀配对，`ntce_repair.py` 第 154–156 行同规则定位答案册。
