# 教资/真题 — 分类原始真题试卷

本目录按考试学段与性质组织 1,390 份原始试卷 CSV。

## 子目录分类
- **初中真题/**：初级中学综合素质、教育知识与能力及各学科真题 CSV。
- **高中真题/**：高级中学综合素质、教育知识与能力及各学科真题 CSV。
- **小学真题/**：小学综合素质、教育教学知识与能力真题 CSV。
- **幼儿真题/**：幼儿园综合素质、保教知识与能力真题 CSV。
- **结构化面试/**：历年结构化面试问答题库 CSV。
- **四川省考/** / **辽宁省考/**：国考前的历史省考真题 CSV。
- **真题精选/**：第三方精选汇总试卷（带标记去重）。
