## 编码与分隔特征（本目录 60 份 CSV 全量字节级扫描，另抽读 3 份文件头核对）

- 编码 UTF-8、无 BOM（BOM 命中 0 份）；换行只用 CRLF（含 CRLF 的文件 49 份，裸 LF 文件 0 份），换行总数 612。
- 单行卷（整卷 0 换行）11 份，1 个换行 0 份，2 个以上换行 49 份。
