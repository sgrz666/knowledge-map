# 教资原始资料/ —— 第三方汇编的教资历年真题/答案原始 CSV 层；由外部采集入库（仓库内无抓取脚本），由 kb_tools/build_kb.py 生成数据集/教资，被 14,500 题的 source.files 反向定位

这一层是交付库 `数据集/教资/`（questions 622 个 JSONL、14,500 题）的源头材料，只读归档、不入库检索：检索面消费的是 build_kb.py 结构化后的 `数据集/教资/questions|materials|cards`。关键别名：仓库根有符号链接 `教资 -> 教资原始资料`（`ls -l` 可见），所以题库里 14,500 题的 `source.files[].path` 与 `kb_tools/build_kb.py` 的 `SRC = ROOT / '教资' / '真题'` 都写死 `教资/真题/` 前缀；`审查/validate_kb.py` 的 Q_SOURCE_UNRESOLVED 判定就是拿这些 path 到 `[仓库根, 数据集目录]` 下找文件（validate_kb.py 第 113–126 行、第 523–528 行），`教资` 链接缺失时全部题目会被判"原题来源不能定位到本地文件"。**写本目录文件一律用真实目录名 `教资原始资料/…`，绝不通过 `教资/` 符号链接路径写。**

## 文件分布（现算，find 全量）

- 总计 1,410 个文件 = 1,390 个 CSV + 14 个 README.md（本文件、`真题/README.md` 与 12 个分类子目录各 1 份）+ 6 个 `.mimosa/` 工具状态 JSON（`真题/.mimosa/finding-ledger` 与 `hook-state` 等，非数据，勿当作语料）。
- CSV 1,390 份 = 695 份真题卷 + 695 份答案卷，按"题文件名 + （答案）"规则命名答案卷（个别变体在（答案）前多一个空格，初中 8 份、高中 6 份）在 4 组目录里 1:1 精确配对（逐目录校验：初中 290/290、高中 286/286、小学 59/59、幼儿 60/60，双向无落单）。
- 全部 1,390 份 CSV：UTF-8、无 BOM、无引号转义。真题卷多行 CRLF，正文以"一、单项选择题"分节、逐行"数字、题干"；1,390 份答案卷全部单行到底（逐字节现算：0 个 CR/LF），形如 `1、B2、A3、D…`——题号与内容之间是顿号"、"（U+3001），不是逗号；主观题号写"参见解析"（现算：整卷只有"参见解析"、无任何选项字母的答案卷，初中/小学/幼儿/高中各 6 份）。部分真题文件正文里出现的半角逗号属于题面文本（现算：初中真题 290 份中 73 份含半角逗号）。
- 覆盖：公共科目（综合素质、教育知识与能力、教育教学知识与能力、保教知识与能力）＋初高中学科知识＋结构化面试问答＋2014 年前后四川/辽宁等省考时期试卷＋"真题精选"汇编卷。

```bash
find 教资原始资料 -name '*.csv' | wc -l                  # 1390
for d in 教资原始资料/真题/*/; do echo "$d $(find "$d" -type f | wc -l)"; done
```
