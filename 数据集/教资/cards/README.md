# 教资KB/cards — RAG 自包含检索卡片库（轨 B）

本目录包含全量 12,881 份 Markdown 自包含试题卡片（一题一卡）。

## 架构说明
- **存储路径**：cards/{学段}/{科目}/{年份场次}/q{序号}.md
- **卡片组成**：
  1. **YAML Frontmatter**：包含考试、学段、题型、分值、挂载知识点与能力、量规外键等完整检索过滤元数据。
  2. **自然语言摘要**：【年份场次 · 学段·科目 · 题型 · 第N题】
  3. **材料与题目正文**：长材料自包含嵌入，直接用于向量 embedding，无需回表拼接。
  4. **星火三段解析**：考点剖析、逐项对比、理论溯源。
