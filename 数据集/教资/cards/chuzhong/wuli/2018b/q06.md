【2018b · chuzhong·wuli · 单选 · 第6题】

如图6所示，在光滑绝缘的水平面上方，有两个方向相反的水平方向匀强磁场，PQ为两个磁场的边界，磁场范围足够大，磁感应强度的大小分别为、。一个竖直放置的边长为、质量为、电阻为的正方形金属线框，以速度垂直磁场方向从图中实线位置开始向右运动，当线框运动到分别有一半面积在两个磁场中时，线框的速度为，则下列结论中正确的是（ ）。

- A. 此过程中通过线框截面的电量为
- B. 此过程中回路产生的电能为
- C. 此时线框的加速度的大小为
- D. 此时线框中的电功率为

**答案:C**

**【结构化解析】**
**考点剖析与关键信息:** 本题综合考查初中物理（实际为高中电磁学内容，但NTCE初中物理试题偶有适度拓展）中电磁感应现象的核心规律：法拉第电磁感应定律、楞次定律、安培力与牛顿第二定律的动态耦合、能量转化与电荷量计算。核心意图是检验考生在多场叠加、边界穿越情境下，对瞬时物理量（加速度、电功率）与过程量（电量、电能）的辨析能力，关键在于识别‘一半面积在两个反向磁场中’这一特殊位置的磁通量变化率、感应电动势、安培力合力及运动状态的瞬时性。
**选项深度对比/得分点:** A项错误：通过线框截面的电量q=ΔΦ/R仅适用于单方向磁通量变化且R恒定的情形；本题中线框跨越反向磁场边界，左右两侧磁通量方向相反，总磁通量Φ= B₁·(L²/2) − B₂·(L²/2) = (B₁−B₂)L²/2，但运动过程中Φ并非单调变化，且电量应由∫i dt = ∫(ε/R)dt = (1/R)∫(dΦ/dt)dt = ΔΦₜₒₜₐₗ/R，而初态Φ₀ = B₁L²，末态（一半在各场）Φ = (B₁−B₂)L²/2，故ΔΦ = Φ − Φ₀ = −(B₁+ B₂)L²/2，但该过程非匀变速，且题目未给出位移或时间，无法直接得选项所列表达式，且选项未体现B₁、B₂差异，属典型‘公式套用不辨前提’陷阱。B项错误：回路产生的电能等于克服安培力做的功，即机械能减少量，应为(1/2)m(v₀²−v²)，但选项给出的是(1/2)m(v₀−v)²，混淆了动能差与速度差平方，违背能量守恒基本形式，属代数运算干扰陷阱。C项正确：当线框一半在B₁场、一半在B₂场（方向相反）时，左右两边均切割磁感线，左侧边（在B₁中）感应电动势E₁ = B₁Lv，方向设为顺时针；右侧边（在B₂中）因B₂反向，等效为−B₂，故E₂ = B₂Lv，方向与E₁相同（由右手定则统一判断），上下边不切割，故总电动势E = (B₁ + B₂)Lv；电流I = E/R = (B₁ + B₂)Lv/R；左侧边受安培力F₁ = B₁IL向左，右侧边受安培力F₂ = B₂IL向左（因电流同向、磁场反向，力同向），故合力F = (B₁ + B₂)IL = (B₁ + B₂)²L²v/R，方向向左；由牛顿第二定律得加速度大小a = F/m = (B₁ + B₂)²L²v/(mR)，与选项一致。D项错误：此时电功率P = I²R = E²/R = (B₁ + B₂)²L²v²/R，而选项写为(B₁ + B₂)Lv²/R，漏掉一个(B₁ + B₂)L因子，属数量级与维度错误（单位已不匹配：选项单位为T·m·m²/s² = T·m³/s²，而功率单位应为W = J/s = T·A·m²/s，明显不符），属单位与公式结构双重陷阱。
**考点溯源与理论依据:** 考点严格对应《中小学教师资格考试标准（物理）》‘物理学科知识’模块中‘电磁感应’条目：要求掌握法拉第定律ε = −dΦ/dt、动生电动势ε = Blv、闭合电路欧姆定律、安培力F = ILB及牛顿第二定律的联合应用；同时关联《义务教育物理课程标准（2022年版）》‘能量’主题下‘电磁感应产生电流的条件及能量转化’；推导步骤需基于：① 瞬时电动势叠加原理（不同区域独立计算后矢量合成）；② 楞次定律确定电流方向→安培力方向；③ 同向安培力叠加求合力；④ F=ma求瞬时加速度。此为电磁感应动力学问题的标准四步建模法，属NTCE高频综合考点。
