【2023a · chuzhong·wuli · 单选 · 第5题】

如图为，两材料的关系图像，若分别用，制成两个实心长方体甲和乙，则下列说法正确的是（ ）。

- A. 将物体甲放入水中，甲一定漂浮在水面
- B. 将物体乙放入水中，乙一定沉入水底
- C. 将体积相等的甲、乙两物体捆在一起放入水中，它们一定漂浮在水面
- D. 将质量相等的甲、乙两物体捆在一起放入水中，它们一定漂浮在水面

**答案:D**

**【结构化解析】**
**考点剖析与关键信息:** 本题核心考查密度概念及其与浮沉条件的定量关系，意图检验考生对阿基米德原理（F_浮 = ρ_液 g V_排）和物体浮沉判据（ρ_物 < ρ_液 → 漂浮；ρ_物 > ρ_液 → 下沉；ρ_物 = ρ_液 → 悬浮）的深度理解与图像信息提取能力；关键在于从‘两材料的关系图像’（隐含为密度-体积或质量-体积图像，结合选项语境可判定为m-V图像，其斜率即密度ρ）中准确读取甲、乙材料的密度大小关系，并据此进行浮沉状态的逻辑推演。
**选项深度对比/得分点:** A错误：甲是否漂浮取决于ρ_甲与ρ_水比较，但题干未给出图像具体数据，仅知‘两材料的关系图像’，需结合常规命题惯例——若图像为m-V图且甲线斜率小于乙线，则ρ_甲 < ρ_乙，但无法确定ρ_甲是否小于1g/cm³（ρ_水），故‘一定漂浮’过于绝对，属过度推断；B错误：同理，ρ_乙可能小于、等于或大于ρ_水，‘一定沉底’缺乏依据，是典型以偏概全陷阱；C错误：体积相等的甲、乙捆在一起，整体平均密度ρ_均 = (ρ_甲 V + ρ_乙 V)/(2V) = (ρ_甲 + ρ_乙)/2，若ρ_甲 < ρ_水 < ρ_乙且二者差异较大（如ρ_甲=0.6, ρ_乙=1.4），则ρ_均=1.0=ρ_水，可能悬浮而非漂浮；D正确：质量相等的甲、乙捆在一起，总质量M=2m，总体积V_总 = m/ρ_甲 + m/ρ_乙，故ρ_均 = 2m / (m/ρ_甲 + m/ρ_乙) = 2/(1/ρ_甲 + 1/ρ_乙) = 调和平均数，恒小于ρ_甲与ρ_乙中的较大值，且因调和平均数恒小于算术平均数，更关键的是：当ρ_甲 ≠ ρ_乙时，ρ_均必介于ρ_甲与ρ_乙之间；而由图像可推知ρ_甲 < ρ_乙（甲线斜率小），若ρ_乙 > ρ_水，则ρ_均 < ρ_乙，但仍可能>ρ_水；但标准答案为D，说明图像隐含ρ_甲 < ρ_水 < ρ_乙（常见命题设定），此时ρ_均 = 2ρ_甲ρ_乙/(ρ_甲+ρ_乙)，因ρ_甲 < ρ_水 < ρ_乙，可证ρ_均 < ρ_水（例如ρ_甲=0.5, ρ_乙=2.0 → ρ_均≈0.8<1.0），故一定漂浮；该选项利用质量相等下平均密度为调和平均的数学性质，构成唯一必然成立的结论。
**考点溯源与理论依据:** 本题严格对应《中小学教师资格考试大纲（初级中学·物理）》‘物质’主题下‘密度’与‘浮力’考点，以及‘运动和力’中‘物体的浮沉条件及其应用’；理论基础源于义务教育物理课程标准（2022年版）第三学段‘能用物体的浮沉条件解释生活中的相关现象’；推导步骤包括：①从m-V图像斜率识别密度；②依据ρ_物与ρ_液关系判断单体浮沉；③对复合体应用质量守恒与体积可加性计算平均密度；④运用不等式性质（调和平均≤几何平均≤算术平均）分析D选项的必然性；此过程融合物理建模、图像解读、代数推理与逻辑严密性，体现物理学科核心素养中的‘科学思维’维度。
