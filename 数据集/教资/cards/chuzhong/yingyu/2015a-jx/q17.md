【2015a-jx · chuzhong·yingyu · 单选 · 第17题】

The correct meaning of a lexical item in a given context is__________

- A. the one provided in a dictionary
- B. the one which best fits the context
- C. the central or core meaning of the item
- D. the one which is assumed to be correct

**答案:B**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：The correct meaning of a lexical item in a given context is__________。选项：Athe one provided in a dictionary；Bthe one which best fits the context；Cthe central or core meaning of the item；Dthe one which is assumed to be correct。给定答案：B
**选项深度对比/得分点:** 语境中词的确切含义是『最贴合语境的那一个』。A词典义、C核心义、D假定正确义均不如B。故选B。
**考点溯源与理论依据:** 关联知识点：词法与词汇；关键词：lexical、morpheme、morphology、vocabulary、word formation、构词、词汇
