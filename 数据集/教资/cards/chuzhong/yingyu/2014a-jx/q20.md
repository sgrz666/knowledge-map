【2014a-jx · chuzhong·yingyu · 单选 · 第20题】

If a teacher starts with language examples and guides students to work out the rules he/she is using the_______ method.

- A. deductive
- B. conducive
- C. inductive
- D. constructive

**答案:C**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：If a teacher starts with language examples and guides students to work out the rules he/she is using the_______ method.。选项：Adeductive；Bconducive；Cinductive；Dconstructive。给定答案：C
**选项深度对比/得分点:** 先举例引导学生总结规则是归纳法（inductive）。A演绎、B有益、D建构均不符。故选C。
