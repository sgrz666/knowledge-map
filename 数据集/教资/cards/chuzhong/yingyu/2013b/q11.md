【2013b · chuzhong·yingyu · 单选 · 第11题】

Which of the following assumptions about vocabulary learning contradicts the modern language teaching theories?（ ）

- A. The best way to learn words is to use them.
- B. The best way to learn vocabulary is via rote-learning.
- C. An English dictionary is an important aid to students.
- D. Learning a word involves learning more than just the word itself.

**答案:B**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：Which of the following assumptions about vocabulary learning contradicts the modern language teaching theories?（ ）。选项：AThe best way to learn words is to use them.；BThe best way to learn vocabulary is via rote-learning.；CAn English dictionary is an important aid to students.；DLearning a word involves learning more than just the word itself.。给定答案：B
**选项深度对比/得分点:** 违背现代词汇教学理论的是『通过死记硬背（rote-learning）学词汇』。A运用、C词典辅助、D词不止学词本身均符合现代理念。故选B。
