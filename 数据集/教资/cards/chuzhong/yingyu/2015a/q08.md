【2015a · chuzhong·yingyu · 单选 · 第8题】

Don´ t be discouraged __________ and you will surely pass the exam．

- A. Make a bit more effort
- B. To make a bit more effort
- C. Making a bit more effort
- D. If you make a more effort

**答案:A**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：Don´ t be discouraged __________ and you will surely pass the exam．。选项：AMake a bit more effort；BTo make a bit more effort；CMaking a bit more effort；DIf you make a more effort。给定答案：A
**选项深度对比/得分点:** 「祈使句 + and + 陈述句」是固定句式，前一分句用动词原形。A「Make a bit more effort」符合该结构。B「To make」为不定式，不能构成祈使句；C「Making」为分词，同样不能；D「If you make a more effort」有两处问题：一是与and重复构成条件，二是more后应接不可数名词effort而非a more effort。故选A。
**考点溯源与理论依据:** 关联知识点：英语语法与句法；关键词：agreement、clause、gerund、grammar、participle、passive、subjunctive、syntax
