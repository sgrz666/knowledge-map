【2015a · chuzhong·yingyu · 单选 · 第10题】

Which of the following best represents the order from a harsh command to a very polite request?
a Could you close the door?
b Close the door．
c Please close the door．
d Would you please close the door?

- A. b-c-a-d
- B. c-b-a-d
- C. d-a-c-b
- D. c-b-d-a

**答案:A**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：Which of the following best represents the order from a harsh command to a very polite request?
a Could you close the door?
b Close the door．
c Please close the door．
d Would you please close the door?。选项：Ab-c-a-d；Bc-b-a-d；Cd-a-c-b；Dc-b-d-a。给定答案：A
**选项深度对比/得分点:** 按语气由严厉到礼貌排序：b「Close the door.」为直接命令，最严厉；c「Please close the door.」加please稍缓和；a「Could you close the door?」用疑问形式进一步委婉；d「Would you please close the door?」would加please最为礼貌。故顺序为b-c-a-d。B、C、D三项的顺序均把最礼貌或最严厉的形式放在了错误位置。故选A。
**考点溯源与理论依据:** 关联知识点：语义语用与语言学；关键词：discourse、implicature、linguistic、pragmatics、presupposition、semantics、speech act、语用
