【2015a · chuzhong·yingyu · 单选 · 第17题】

The correct meaning of a lexical item in a given context is __________．

- A. the one provided in a dictionary
- B. the one which best fits the context
- C. the central or core meaning of the item
- D. the one which is assumed to be correct

**答案:B**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：The correct meaning of a lexical item in a given context is __________．。选项：Athe one provided in a dictionary；Bthe one which best fits the context；Cthe central or core meaning of the item；Dthe one which is assumed to be correct。给定答案：B
**选项深度对比/得分点:** 词汇在特定语境中的意义即语境意义，指B「the one which best fits the context」（最契合该语境的意义）。A「the one provided in a dictionary」是脱离语境的词典义；C「the central or core meaning」是词汇的核心义；D「the one which is assumed to be correct」表述含混，不是语境意义的定义。故选B。
**考点溯源与理论依据:** 关联知识点：词法与词汇；关键词：lexical、morpheme、morphology、vocabulary、word formation、构词、词汇
