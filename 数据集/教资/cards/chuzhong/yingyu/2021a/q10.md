【2021a · chuzhong·yingyu · 单选 · 第10题】

Which of the following describes the language phenomenon that a bilingual speaker uses two languages alternatively in the same conversation?

- A. Address forms.
- B. Ethnic dialect.
- C. Register variables.
- D. Code-switching.

**答案:D**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：Which of the following describes the language phenomenon that a bilingual speaker uses two languages alternatively in the same conversation?。选项：AAddress forms.；BEthnic dialect.；CRegister variables.；DCode-switching.。给定答案：D
**选项深度对比/得分点:** 双语者在同一会话中交替使用两种语言，是语码转换现象。D「Code-switching」符合。A「Address forms」是称呼语、B「Ethnic dialect」是民族方言、C「Register variables」是语域变体，均不描述交替使用两种语言的行为。故选D。
**考点溯源与理论依据:** 关联知识点：语义语用与语言学；关键词：discourse、implicature、linguistic、pragmatics、presupposition、semantics、speech act、语用
