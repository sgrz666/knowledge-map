【2021b · gaozhong·huaxue · 单选 · 第3题】

下列离子方程式书写正确的是（ ）。

- A. 向碳酸镁中加入稀盐酸：
- B. 向浓碱溶液中加入铝片：
- C. 氯化钙溶液与碳酸氢钾溶液混合：
- D. 用惰性电极电解氯化钠溶液：

**答案:D**

**【结构化解析】**
**考点剖析与关键信息:** 本题综合考查高中化学核心素养中的‘证据推理与模型认知’，聚焦离子方程式书写的规范性要求（强弱电解质、难溶物/气体标注、电荷守恒、原子守恒、反应实际可行性），关联电化学（D项电解原理）、无机元素化合物性质（A项MgCO₃溶解性与酸反应、B项Al的两性、C项Ca²⁺与HCO₃⁻双水解与沉淀转化）及溶液中离子反应规律（化学计量与溶液中的离子共存与反应限度）。考查意图在于甄别考生对真实反应体系的理解深度，而非机械套用书写模板。
**选项深度对比/得分点:** A项错误：碳酸镁（MgCO₃）是难溶弱电解质，不能拆为Mg²⁺和CO₃²⁻，应保留化学式；正确写法为MgCO₃ + 2H⁺ → Mg²⁺ + CO₂↑ + H₂O。干扰陷阱在于混淆‘难溶盐’与‘可溶碳酸盐’（如Na₂CO₃）的拆分规则。B项错误：铝片与浓碱（如NaOH）反应生成[Al(OH)₄]⁻（或写作AlO₂⁻），但‘浓碱溶液’未指明具体碱，且反应需水参与，正确离子方程式为2Al + 2OH⁻ + 6H₂O → 2[Al(OH)₄]⁻ + 3H₂↑；选项若简写为2Al + 2OH⁻ → 2AlO₂⁻ + H₂↑则违背原子守恒与实际水合环境，属常见简化错误。C项错误：CaCl₂与KHCO₃混合，Ca²⁺与HCO₃⁻不直接生成CaCO₃沉淀，因HCO₃⁻水解程度弱且Ca(HCO₃)₂可溶；需加热或浓度较高时才发生2HCO₃⁻ ⇌ CO₃²⁻ + CO₂↑ + H₂O，继而Ca²⁺ + CO₃²⁻ → CaCO₃↓，故常温混合无明显反应，不能直接写Ca²⁺ + 2HCO₃⁻ → CaCO₃↓ + CO₂↑ + H₂O（该式实为加热条件下的总反应，且未满足电荷守恒：左侧电荷+2，右侧0）。D项正确：惰性电极电解NaCl溶液，阳极Cl⁻放电：2Cl⁻ → Cl₂↑ + 2e⁻，阴极H₂O得电子：2H₂O + 2e⁻ → H₂↑ + 2OH⁻，总离子方程式为2Cl⁻ + 2H₂O → Cl₂↑ + H₂↑ + 2OH⁻，符合事实、守恒、标注规范。
**考点溯源与理论依据:** 依据《普通高中化学课程标准（2017年版2020年修订）》必修模块‘主题3：物质结构基础与化学反应规律’中‘能正确书写离子方程式，理解其意义’；对应《中小学教师资格考试大纲（化学）》‘化学学科知识运用能力’要求：掌握电解质溶液、氧化还原反应、电化学等核心概念及其定量分析方法。本题涉及《课标》学业质量水平3‘能基于证据对复杂现象进行分析推理’，推导步骤包括：①判断物质溶解性与强弱电解质属性（查溶解性表、记忆常见难溶物）；②分析反应发生的热力学可行性（如Al与OH⁻反应ΔG<0，Ca²⁺与HCO₃⁻常温不沉淀）；③应用电解原理确定电极反应（放电顺序：Cl⁻ > OH⁻；H₂O还原优先于Na⁺）；④验证四大守恒（质量、电荷、电子、原子）。
