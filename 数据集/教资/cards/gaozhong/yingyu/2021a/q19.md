【2021a · gaozhong·yingyu · 单选 · 第19题】

Which of the following should be discouraged concerning the use of internet resources?（ ）

- A. Teachers depend on internet resources for teaching materials.
- B. Teachers use internet resources to supplement their textbooks.
- C. Teachers adapt internet resources before using them for language input.
- D. Teachers select internet resources according to their teaching purpose.

**答案:A**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：Which of the following should be discouraged concerning the use of internet resources?（ ）。选项：ATeachers depend on internet resources for teaching materials.；BTeachers use internet resources to supplement their textbooks.；CTeachers adapt internet resources before using them for language input.；DTeachers select internet resources according to their teaching purpose.。给定答案：A
**选项深度对比/得分点:** 教师完全依赖网络资源会丧失教学的针对性与自主性。A「Teachers depend on internet resources for teaching materials」应被劝阻。B补充教材、C先改编再使用、D按需选择，均为合理做法。故选A。
