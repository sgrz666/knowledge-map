【2015a · gaozhong·yingyu · 单选 · 第10题】

The language used to describe the language itself is called__________.

- A. paralanguage
- B. special language
- C. metalanguage
- D. interlanguage

**答案:C**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：The language used to describe the language itself is called__________.。选项：Aparalanguage；Bspecial language；Cmetalanguage；Dinterlanguage。给定答案：C
**选项深度对比/得分点:** 用于描述语言本身的语言称为元语言。C「metalanguage」符合。A「paralanguage」副语言指语调、手势等非语言伴随特征；B「special language」与D「interlanguage」中介语（指学习者介于母语与目标语之间的语言系统）均不符合定义。故选C。
**考点溯源与理论依据:** 关联知识点：二语习得与学习策略；关键词：acquisition、interlanguage、learning strateg、motivation、transfer、二语、语言习得
