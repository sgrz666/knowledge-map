【2020b · gaozhong·yingyu · 单选 · 第6题】

Without facts we can't form worthwhile opinions for we need to have factual knowledge ________ our thinking.

- A. which to be based upon
- B. upon which to base
- C. which to base upon
- D. upon which to be based

**答案:B**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：Without facts we can't form worthwhile opinions for we need to have factual knowledge ________ our thinking.。选项：Awhich to be based upon；Bupon which to base；Cwhich to base upon；Dupon which to be based。给定答案：B
**选项深度对比/得分点:** base A upon B结构转化为不定式时，介词upon需提前：upon which to base our thinking。B「upon which to base」符合。A「which to be based upon」语序不当且为被动、C「which to base upon」未提前介词、D「upon which to be based」为被动但thinking是base的施事。故选B。
**考点溯源与理论依据:** 关联知识点：英语语法与句法；关键词：agreement、clause、gerund、grammar、participle、passive、subjunctive、syntax
