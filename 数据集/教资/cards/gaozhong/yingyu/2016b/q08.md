【2016b · gaozhong·yingyu · 单选 · 第8题】

Which of the following shows the proper rhythmic pattern of the sentence?

- A. This is a 'question for 'Doctor 'Carrington.
- B. This is 'a 'question for 'Doctor Carrington.
- C. This is a 'question 'for Doctor 'Carrington.
- D. This 'is a 'question for 'Doctor 'Carrington.

**答案:A**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：Which of the following shows the proper rhythmic pattern of the sentence?。选项：AThis is a 'question for 'Doctor 'Carrington.；BThis is 'a 'question for 'Doctor Carrington.；CThis is a 'question 'for Doctor 'Carrington.；DThis 'is a 'question for 'Doctor 'Carrington.。给定答案：A
**选项深度对比/得分点:** 句子重音落在实词上：question、Doctor、Carrington。A项标注符合规律。B项漏标Carrington；C项把for误作重读；D项把This与is都标重，虚词过度重读。故选A。
