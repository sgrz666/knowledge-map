【2013b-jx · gaozhong·yingyu · 单选 · 第12题】

Which of the following assumptions about vocabulary learning contradicts the modem language teaching theories? （ ）

- A. The best way to learn words is to use them.
- B. The best way to learn vocabulary is via rote-learning.
- C. An English dictionary is an important aid to students.
- D. Learning a word involves learning more than just the word itself.

**答案:B**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：Which of the following assumptions about vocabulary learning contradicts the modem language teaching theories? （ ）。选项：AThe best way to learn words is to use them.；BThe best way to learn vocabulary is via rote-learning.；CAn English dictionary is an important aid to students.；DLearning a word involves learning more than just the word itself.。给定答案：B
**选项深度对比/得分点:** 现代语言教学理论强调在语境中、通过使用来学习词汇，反对孤立死记硬背。B「The best way to learn vocabulary is via rote-learning」与之相悖。A「The best way to learn words is to use them」符合使用中学；C「An English dictionary is an important aid」符合工具观；D「Learning a word involves learning more than just the word itself」符合词汇学习的多维度观。故选B。
