【2016b-k2 · gaozhong·yingyu · 单选 · 第13题】

It is suggested that teachers should not interrupt students for error correction when the activity aims at______.

- A. accuracy
- B. fluency
- C. complexity
- D. cohesion

**答案:B**

**【结构化解析】**
**考点剖析与关键信息:** 题干考查：It is suggested that teachers should not interrupt students for error correction when the activity aims at______.。选项：Aaccuracy；Bfluency；Ccomplexity；Dcohesion。给定答案：B
**选项深度对比/得分点:** 当活动目标为流利度时，教师不宜频繁打断纠错，否则会破坏交际连贯性与学生表达意愿。B「fluency」符合。A「accuracy」准确性目标下纠错是必要的；C「complexity」与D「cohesion」均非「不打断纠错」的直接理由。故选B。
**考点溯源与理论依据:** 关联知识点：英语写作与篇章；关键词：coherence、cohesion、composition、essay、writing、写作
