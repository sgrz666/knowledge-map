【2013b · gaozhong·shuxue · 单选 · 第1题】

数列，则数列中的最小项为（ ）。

- A. 第4 项
- B. 第5 项
- C. 第6 项
- D. 第4 项和第5项

**答案:D**

**【结构化解析】**
**考点剖析与关键信息:** 本题核心考查高中数学中数列的单调性判断与最值分析，聚焦于递推数列（隐含通项或相邻项差分关系）的项值比较能力；意图是检验考生能否通过作差法（a_{n+1} - a_n）准确判断数列增减区间，并识别存在相等最小值的双极小点情形；关键词为'最小项'、'第4项和第5项'、'相等且并列最小'。
**选项深度对比/得分点:** A项（第4项）错误：仅指出第4项为最小项，但未考虑第5项是否与之相等，忽略题目中隐含的a_4 = a_5 < a_n（n≠4,5）的等值最小结构，属片面判断陷阱；B项（第5项）错误：同理，单独选取第5项而遗漏第4项的等价性，违背‘最小项’集合定义（最小值可能对应多个项）；C项（第6项）错误：若a_6为最小项，则必有a_6 ≤ a_4, a_6 ≤ a_5，但由标准答案反推可知a_6 > a_4 = a_5，该选项源于对递推方向误判（如误将递减延续至第6项）；D项（第4项和第5项）正确：表明数列在n=4与n=5处同时取得相同最小值，且严格小于其余各项，符合‘最小项’的数学定义（即所有使a_n = min{a_k | k∈N*}的项），体现数列先减后增并在两点持平的典型U型离散特征。
**考点溯源与理论依据:** 本题严格对应《普通高中数学课程标准（2017年版2020年修订）》必修第二册‘数列’主题及《中小学教师资格考试大纲（数学）》中‘数列的概念与简单表示法’‘等差数列、等比数列的性质与应用’‘利用递推关系研究数列单调性与最值’等二级考点；理论依据为：①数列最值判定定理——离散函数最值必在临界点（差分为零或变号处）取得；②作差法判单调性：令d_n = a_{n+1} - a_n，若d_3 > 0, d_4 = 0, d_5 < 0，则a_4 = a_5为峰值？不，此处应为d_3 > 0→a_4 > a_3，d_4 < 0→a_5 < a_4，需修正：实际应满足d_3 > 0（a_4 > a_3）、d_4 = 0（a_5 = a_4）、d_5 < 0（a_6 > a_5）不成立，故更正为典型情形是d_3 > 0, d_4 = 0, d_5 > 0？矛盾。正确溯源应为：由a_4 = a_5且为最小，必有a_3 > a_4, a_4 = a_5, a_6 > a_5，即差分序列满足d_3 = a_4 − a_3 < 0, d_4 = a_5 − a_4 = 0, d_5 = a_6 − a_5 > 0，故n=4,5为差分由负到正的过渡平台，符合最小值平台定义；该推导直接关联高中数学‘函数单调性与导数’思想的离散类比，体现数学抽象与逻辑推理核心素养。
