# 数据集/教资/graph/ —— L0–L7 图导出层：kb_tools/build_graph.py 产 nodes.jsonl/edges.jsonl，services/knowledge/graph_index.py 消费

- **层位**：八层体系全部层级的拓扑导出（L0 条款 2,320、L1 考试 7、L2 模块 38、L3 素养与能力 51、L4 考点 791、L5 材料 586、L6 题与量规 18,303、L7 资源 11），是图的导入格式，不是事实源——事实源在 `questions/`、`outline/`、`materials/`、`rubrics/`、`resources/` 与 `权威资料/`。
- **生成**：`kb_tools/build_graph.py::build()` 全量重导并 `atomic_write` 本目录 `nodes.jsonl`、`edges.jsonl`，同时回写 `../MANIFEST.json` 的 `graph` 与 `eight_layer_hierarchy` 块；命令 `python kb_tools/build_graph.py`。`edges_curated.jsonl` 是本目录唯一人工维护的策展源文件，导出时被并入 `edges.jsonl`。
- **消费**：`services/knowledge/repository.py::graph_records()`（`GRAPH_FILES["ntce"]` 指向本目录两个 jsonl，是唯一读入口）→ `services/knowledge/graph_index.py::GraphIndex`（16 词边名白名单、方向语义、先修启用判断都在这里编码）；`services/planner`、`services/retrieval` 经 `get_graph_index('ntce')` 取遍历结果。
- **门禁**：`python -m pytest tests/test_graph_direction_contract.py tests/test_ntce_hierarchy_contract.py -q`（边名、方向、端点类型、L0 全量入图、单一 layer 字段）；`python -m pytest tests/test_acceptance_gate.py -q`（白名单越界报错、先修禁用、缓存换代）。

## 文件清单

- `nodes.jsonl`（7,428,948 B / 22,107 行）—— 节点实体，一行一 JSON `{id, layer, type, name, 类型专属字段}`，按 `id` 升序，id 全局唯一（重复 id 首次写入后丢弃）。`layer` 取值即规范 §3.2 的 L0–L7 一套，`hierarchy_level` 第二套字段由测试禁止。`type` 分布现算：standard 60 / exam_requirement 2,260 / exam 7 / literacy 7 / ability 44 / module 38 / knowledge_node 791 / material 586 / question 14,500 / rubric 3,803 / resource 11。rubric 3,803 = 3,736 个题内练习框架节点（id 形如 `rubric.<question_id>`，`review_status=practice_framework_pending_subject_expert`）+ 6 个 `rubrics/*.json` 加权量规实体（`review_status=needs_fix`）+ 61 个官方面试细则参照节点（`official=true`、`review_status=question_task_mapping_pending_review`）。question 节点镜像题记录状态：`review` = needs_fix 13,655 / quarantined 845，`answer_status` = letter_only 10,167 / reference_only 3,339 / source_conflict 845 / missing 149。exam_requirement 全部 `verified=false`（`verification_scope=extracted_clause_pending_review`）；60 个 standard 节点 `verified=true`，但该布尔只覆盖 `official_source_acquisition`（原件取得核对），不含条款-考点映射。id 命名：考点 `ntce.<level>.<subject>.m/s…`、省考 `shengkao.…`、条款 `ntce.outline.*.rNNN`/`law.*.rNNN`、资源 `ntce.res.*`。由 `python kb_tools/build_graph.py` 重生成，**不要手改**。
- `edges.jsonl`（12,839,508 B / 96,785 行）—— 边集合，一行一 JSON `{src, dst, type, 审核字段}`，按 (src, dst, type) 升序且三元组去重。边名白名单就是 `services/knowledge/graph_index.py::ALLOWED_EDGE_TYPES` 里的 16 个，按源码顺序：`specifies`、`contains`、`targets`、`supports_ability`、`has_rubric`、`refers_to_material`、`has_child`、`assesses`、`prerequisite_of`、`comprises`、`basis`、`aligned_to_requirement`、`confused_with`、`misconception_lead_to`、`supports_resource`、`supplements_resource`；出现第 17 个名字运行时抛 `UnknownEdgeTypeError`。现算各边数量与方向（方向一律"支撑方 → 被支撑方"）：`assesses` 23,220（knowledge_node → question，查"这题考什么"要走入边）、`aligned_to_requirement` 32,806（exam_requirement → 知识点|题|量规|资源|模块）、`supports_ability` 18,696（ability → 知识点|question）、`contains` 14,709（exam → module、module → 题|知识点）、`has_rubric` 3,736（question → 题内框架节点，全部指向 `rubric.<question_id>`，6 个加权实体被引用数为 0；选择题无此边）、`specifies` 2,260（standard → exam_requirement）、`has_child` 620（outline 父节点 → 子节点）、`refers_to_material` 586（question → material）、`prerequisite_of` 31（knowledge_node → knowledge_node）、`comprises` 44（literacy → ability）、`basis` 36（standard → module，`mapping_status=scope_match_pending_review`）、`targets` 7（exam → literacy）、`confused_with` 7、`misconception_lead_to` 3、`supports_resource` 13（ability → resource）、`supplements_resource` 11（knowledge_node → resource）。审核态现算：`assesses` verified 全为 false（置真条件是题记录 `review.tagger=expert`，全库 0 题）；`supports_ability`、`basis` verified 全 false；`aligned_to_requirement` 32,790 false + 16 无字段；其余结构性边（contains/specifies/has_rubric 等）不带 verified 字段。31 条 `prerequisite_of` 实测 `status=proposed_pending_review` 全量、`active_for_learning_path=false` 全量、`reviewed_by=null` 全量 ⇒ `GraphIndex.prerequisites_active` 现算为 False，学习路径不含前置阻断。由 `python kb_tools/build_graph.py` 重生成，**不要手改**。
- `edges_curated.jsonl`（7,240 B / 23 行）—— 可版本化的策展源边，本目录唯一允许手改的文件。现算类型分布：`prerequisite_of` 13（字段 `{src,dst,type,rationale,review_status,status,active,reviewed_by,declared_status,active_for_learning_path}`——`declared_status=verified` 是旧版脚本自评的降级留痕，当前 `status/review_status=proposed_pending_review`、`active=false`、`active_for_learning_path=false`、`reviewed_by=null`）、`confused_with` 7（`{src,dst,type,note,active:true}`）、`misconception_lead_to` 3（`{src,dst,type,pattern,active:true}`）。23 行无一有具名审核人。与 `edges.jsonl` 的关系：`build_graph()` 读取本文件合并进导出层（覆盖方向是 curated → edges，单向），只接受上述 3 种类型，端点不在节点集或出现词表外类型直接抛错；先修边若声明 verified/approved/expert_reviewed 却无审核人，`build_graph.py` 第 192–198 行自动降级并关闭生效标记。核定一条先修边的动作是改本文件的 `reviewed_by`、`status`、`active` 后重跑 `python kb_tools/build_graph.py`（口径见 `审查/待复核清单.md` §1.1、§7，该清单是 `审查/build_review_queue.py` 生成物，只可引用不可改）。

## 改这里之前要知道的

- `nodes.jsonl`、`edges.jsonl` 是生成物：整目录可删除后由 `build_graph.py` 重建；手改会在下一次重跑时被覆盖，且 `kb_tools/ntce_verify.py --check-idempotence` 把 `graph/*.jsonl` 的 sha256 纳入双跑快照，改了就会红。
- 边名 16 词是数据契约：加第 17 个词要同时改 `graph_index.py::ALLOWED_EDGE_TYPES`、`tests/test_graph_direction_contract.py::ALLOWED`（含端点类型对）、`build_graph.py` 常量，并重导两库图谱；`docs/agent_architecture.md` §3.4 归教研核定。
- 图谱从不升级审核状态：`GraphIndex` 对 `verified/mapping_status/active_for_learning_path` 原样透传；想让某结论"已核对"，去改上游题记录或条款文件，不是改这里。
- 隔离题（`review=quarantined`、`answer_status=source_conflict` 共 845）的题节点只是镜像，`services/knowledge/trust.py` 的 `servable_in_paper` 闸门仍把它们挡在组卷、判分、召回之外——图里存在不等于可用。
- `services/knowledge/repository.py` 的缓存只跟踪 `graph/nodes.jsonl`、`edges.jsonl`（含 generation 换代），**不跟踪** `edges_curated.jsonl`：改了策展文件必须重跑 `build_graph.py` 才会生效到运行时。
- README.md 不会被当数据：`build_graph.py` 扫 `rubrics/*.json` 时显式跳过 `README.md`，`审查/validate_kb.py` 同样跳过，`ntce_verify.py` 快照 glob 只收 `*.jsonl`/`*.json`。
- 先修边的 31 = 本文件 13 条 + `build_graph.py` 内置 `DEPENDENCIES` 字典按学科卷生成的 18 条（数学 3、物理 2、化学 2、生物 1、信息技术 1，各乘初中/高中两个学段）；那 18 条不经过本文件，删掉本文件的先修行不会让它们消失。
- 旧值修正：本目录 2026-10-11 版 README 写 `edges_curated.jsonl` "先修候选 13 条"——现算该文件为 23 行（先修 13 + `confused_with` 7 + `misconception_lead_to` 3），已按现算修正。
