# 教资KB/materials — 共享长材料库（L5）

本目录存放材料分析题、案例分析题、教学设计题所引用的 586 篇共享长材料 JSONL。

## 数据特点
- 符合 [schemas/material.json](../schemas/material.json) 规范。
- 包含 material_id、kind（案例材料/教学设计教材）、	ext（正文）、word_count 及 used_by_questions（反向引用列表）。
- 一份材料存一次，支撑大题下多个小问共享引用。

## 子目录
按学段分布：youer/, xiaoxue/, chuzhong/, gaozhong/, zhongxue/。
