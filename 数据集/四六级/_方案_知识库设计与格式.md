## 2. 模块划分（6 个检索域 + 2 个支撑层）

你提出的"单词 / 作文 / 真题"三分是对的，我按 RAG 检索粒度和 Agent 用途细化为 6 库。核心原则：**一条记录 = 一个检索原子（chunk），自带全部元数据，跨 chunk 不需要上下文拼装**。

| # | 模块 | 内容 | 主要来源 | Agent 用途 |
| --- | --- | --- | --- | --- |
| A | `vocabulary/` 词汇 | 大纲词 ~8800、1500 核心词、高频词组、翻译热点主题词 | 【4】xls + 四六级单词/ | 单词查询、造句、按话题/难度选词、翻译词汇支援 |
| B | `questions/` 真题题库 | 真题逐题拆分（听力/阅读客观题） | 【1】真题+解析册 | 刷题、按知识点/题型/年份检索、错题归因、组卷 |
| C | `passages/` 长语料 | 阅读文章原文、听力原文（含音频路径） | 【1】【2】 | 阅读精读、听力跟读、题目溯源定位 |
| D | `writing/` 写作 | 历年真题题目+范文（带结构标注）、模板句（按功能逐条） | 【2】范文 PDF +【3】 | 范文检索、AI 批改对照、模板句精准引用 |
| E | `translation/` 翻译 | 历年真题中文段落+参考译文+主题标注 | 【2】翻译真题/范文 PDF | 翻译练习、译文对照、主题词联想 |
| F | `exam_guide/` 考试说明 | 题型结构、分值、时间分配、报名规则 | 公开考试说明整理 | 回答"考试怎么考"类规则问题 |
| G | `ontology/` 本体层 | 考试→模块→题型→知识点树（L1–L3） | 四六级考纲结构化 | 全库挂载骨架、诊断/推荐路径依据 |
| H | `manifest/` 清单层 | 试卷清单、统计、来源→产物映射日志 | 生成产物 | 可追溯、可纠错、增量更新 |

> 专项题（【2】）不单独建库：它与真题是同一批题目的不同视图。入库后每题带 `module`/`question_type` 标签，"阅读专项"等价于按标签过滤，天然去重。
> 听力 MP3（120 个）不进向量库，只在听力原文记录里登记 `audio` 相对路径，Agent 需要播放时按路径取原文件。

## 4. 记录格式字典（JSONL，每行一条）

**统一约定**
- `id` 全局唯一：`{exam小写}.{模块}.{年月}_p{套}.{序号}`，如 `cet6.r.2022-06_p1.q26`
- `text` 字段 = 预渲染检索文本（含元信息前缀），**直接喂 embedding**；其余字段入库时作为 metadata 过滤条件
- `source.origin_file` 记录原始资料相对路径 → 任何记录可回溯到源文件
- `review.status`：`auto_parsed`（自动拆分未复核）→ `checked`（抽样核对通过）→ `expert_reviewed`（人工审核）
- 试题解析结构沿用需求文档 3.3：`key_info / option_compare / trace_back`

### A. 词汇 word
```json
{"id":"cet4.w.abandon","word":"abandon","phonetic":"/əˈbændən/","level":"CET-4","tier":"outline","pos_meaning":"v. 遗弃；离开；放弃；终止 n. 放任，狂热","cse_level":4,"source":{"origin_file":"【4】四六级大纲词及核心词/.../01.大学英语四级词汇完整带音标-正序版.xls"},"review":{"status":"checked"},"text":"abandon /əˈbændən/ 【四级大纲词汇】v. 遗弃；离开；放弃；终止 n. 放任，狂热"}
```
`tier`：`outline`（大纲）/ `core`（核心1500）/ `highfreq`（高频）；六级词表与四级取差集，共有的词标 `level: "CET-4/6"`。

### B. 真题 question
```json
{"id":"cet6.l.2022-06_p1.q01","exam":"CET-6","year":"2022-06","paper":1,"module":"听力","question_type":"长对话","number":1,"group":"secA.conv1","passage_id":"cet6.l.2022-06_p1.secA.conv1","stem":"What do we learn about the man?","options":{"A":"He is a staff writer.","B":"He is an adventurer.","C":"He is an author of fiction.","D":"He is a father of four kids."},"answer":null,"analysis":null,"knowledge_nodes":["cet6.listen.detail"],"difficulty":null,"source":{"origin_file":"【1】.../2022年6月英语六级真题第一套.docx","analysis_file":"【1】.../2022.06英语六级考试解析第1套.pdf"},"review":{"status":"auto_parsed"},"text":"【2022年6月六级真题第1套·听力·长对话】1. What do we learn about the man? A) He is a staff writer. B) ... "}
```
- `answer`/`analysis` 由解析册二次填充（答案速查 PDF 优先），`analysis_status` 记录解析切分置信度
- 阅读题 `passage_id` 指向 passages 库，题干不重复携带全文
- `knowledge_nodes` 先按题型/话题规则自动挂载，`difficulty` 预留（IRT 校准后回填）

## 6. RAG 接入约定（写入 README）

- **分块**：1 记录 = 1 chunk，无二次切分；embedding 输入用 `text` 字段
- **混合检索**：向量相似（text）+ metadata 过滤（exam/year/module/question_type/tier/theme/knowledge_nodes）+ 词汇精确查询直接查 jsonl（不走向量）
- **自包含**：题目 chunk 内含题干+选项+答案+解析，命中即完整可用；文章长文本单独成 chunk，通过 id 关联
- **Agent 工具化建议**：`查词(word)`、`搜题(过滤条件)`、`取文章(id)`、`找范文(主题/年份)`、`知识树(节点)` 五个检索工具即可覆盖主要学习场景

## 7. 风险与如实说明

1. **2026.6 真题册/解析册为扫描件**（无文本层）：首期不收录逐题内容，仅在 papers 清单登记原件路径；后续可加 OCR（PaddleOCR）补录。其余年份多数 PDF 有文本层，逐个验证后收录。
2. **解析册按题号切分**依赖各年份排版规律，预计 85–95% 可自动对齐；对不上的题 `answer` 置空并标记，需人工抽查（agent 场景下宁可答案缺失也不给错答案）。
3. **zip 内 2015–2021 合集**需先解包评估质量，质量差的年份仅收录答案+解析文本。
4. **版权**：资料仅供个人学习，知识库标注 license=internal，不对外分发。
5. 听力 MP3 只登记路径不做 ASR（原文 PDF 已覆盖转录需求）；后续若需音字对齐可加 whisper 时间戳。
