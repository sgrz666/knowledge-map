- 角色：CET-4 全部题库记录；上一级 `../README.md` 说明全库口径，本目录 60 个数据文件共 2591 条记录（客观题 2445 + 写作 73 + 翻译 73）。
- 生成：docx 场次由 `scripts/build_questions.py --src <资料合集> --stage scripts/_staging --kb 数据集/四六级` 产出（输入 `_staging/cet4/` 38 份 docx）；2024-12/2025-06/2025-12 三个场次无 docx，由 `scripts/build_questions_pdf.py --src --kb` 产出（脚本 docstring 声明的范围，其余卷文件归属 docx 管线）；`writing.jsonl`/`translation.jsonl` 由 `scripts/unify_writing_translation.py` 从 writing/model_essays.jsonl、translation/items.jsonl 并入。修复脚本（fill_answers*、migrate_v2_schema、repair_kb、correct_misaligned_answers、quarantine_*、restore_original_stems、repair_passage_references 等）对卷文件就地增补字段。
- 消费：`services/knowledge/repository.py`（QUESTION_ROOTS 含本目录）、`scripts/generate_cards.py` → cards/cet4、`scripts/build_graph.py` → L6 节点、`scripts/generate_paper_specs.py` → manifest/paper_specs.jsonl。
- 门禁：`tests/test_cet_eight_layer_contract.py`（附录 A.1 Schema 合规）、`tests/test_status_vocabulary.py`（六态 review.status/五态 answer_status）、`tests/test_cet_passage_references.py`、`tests/test_cet_repair.py`、`审查/validate_kb.py`。禁止手改：全部行由脚本重生成/幂等合并。
- 命名：`{YYYY-MM}_p{n}.jsonl`（考次_卷次）；question_id 形如 `cet4-2015-06-p1-listening-1`；卷文件内一行为一题。整卷 55 条 = 听力 25（短篇新闻7+长对话8+听力篇章10）+ 阅读 30（选词填空10+长篇阅读10+仔细阅读10）；第 2/3 套多卷场次听力与第 1 套共用，源里只有阅读时仅落阅读题（30/20/23 条等）；空文件为占位（源未入库），全目录 6 个。
