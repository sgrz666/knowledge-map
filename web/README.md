# web/ —— 浏览器直接加载的四个静态文件：无构建的单页工作台，界面按视图切进两个 JS

这个目录放**前端全部**：`index.html`（骨架与所有控件 id）、`app.js`（公共外壳 + 学习助手 / 练习 / 学情 / 面试单件 / 审计 / 设置）、`workflows.js`（学习计划 / 知识点 / 服务端计时模考 / 面试训练会话）、`styles.css`（压缩后的样式）。没有框架、没有打包器、没有 `package.json`；`docs/web_agent_usage.md` 第 23 行的口径是"当前运行不要求 Node.js 或 Chroma"。写它的人只碰这四份文件，读它的是 `services/app.py`：`WEB_ROOT = Path(__file__).resolve().parents[1] / "web"`，`app.mount("/assets", StaticFiles(directory=WEB_ROOT, check_dir=False), name="web-assets")`，`GET /` 用 `FileResponse(WEB_ROOT / "index.html", headers={"Cache-Control": "no-store"})`。起服务与验收：

```powershell
.\start_web.ps1                 # 默认 127.0.0.1:8000；首次可 .\start_web.ps1 -Install
.\start_web.ps1 -Port 8010      # 端口被占用时（脚本最后一行是 python -m uvicorn services.app:app）
python -m pytest tests/test_web_workbench.py tests/test_services_api.py -q
```

后一条本轮实测 **34 passed / 71.08s**，钉的是 `/api/v1/web/*` 的契约（接口路径、字段、鉴权、Key 不外泄），不是页面渲染；本目录没有 JS 测试运行器，改完界面只能开浏览器按下面的手工点自查（本轮未启动浏览器，不在这里声称看过页面）。

- `styles.css`（12 行，非人类排版）—— 压缩过的唯一样式表。第 2 行 `:root` 定义 11 个变量（`--paper:#f7f5ef`、`--white:#fffefa`、`--ink:#253a32`、`--muted`、`--accent:#b28b4a` 等），第 3 行是一条 **11740 字符**的巨型规则（从 `*{box-sizing:border-box}` 起串完 body / 侧栏 / 卡片 / `.question-card` / `.answer-result` / `.bar-row .bar-track .bar-fill` / `.task-state` / `.study-*` / `.notice` / `.toast` 等全部界面类），第 4–5 行是 `.scope-bar label` 与 `.dimension-feedback`，第 6–11 行是断点：`min-width:1600px`、`max-width:1150px`、`max-width:850px`（出现两次，后一条管 `.app-shell` 单列）、`max-width:480px`、`prefers-reduced-motion:reduce`，第 12 行 `.knowledge-layout` 的 sticky grid。类名与两个 JS 里 `el(tag, text, className)` 的第三参数是隐式契约，改名要三处一起改。

## 无 Key 降级提示落在哪几处

1. `#model-indicator`（侧栏底部）：`applySettings()` 里按 `state.key` 切"规则模式"/"模型配置已就绪"。
2. `#settings-shortcut`（顶栏）："连接 DeepSeek ↗"/"模型配置 ↗"。
3. `#chat-status`（输入框下方）：`chat()` 期间"正在读取题库、查找依据"+ 有 Key 才追加"并请求模型…"。
4. `.message-meta`（每条回答下）：`data.model.ok` 为假显示 **"规则答复 · 模型未参与"**；有 Key 但未通过校验才额外渲染红色 errors。
5. 回答正文本身：无模型时 `services/web/service.py::chat` 返回的是规则文案（考纲条款原文 / "找到以下相关材料" / "当前范围没有召回可用证据"），都自带"当前为规则检索"字样，前端原样显示。
6. `narrate` 的错误语（`services/web/provider.py`）"尚未在网页填写 API Key，当前使用本机规则功能。请在模型与设置中填写 Key 后测试连接。"—— 面试单件视图用 `notices(data.model.errors)` 直接把它摊开。
7. `#model-test-result`：`web/model/test` 失败时把 `errors` .join 成红色 notice。
8. `#fatal`（顶部横幅）：`init()` 拉不到 `web/bootstrap`（后端没起 / 令牌不对）时显示，同时 `#scope-count` 写"知识库未连接"。
9. `.quiet-note`（对话页脚）与 `#view-chat` 侧栏：常驻口径文本，说明研究档与待核定项。

## 改这里之前要知道的

- 脚本顺序是硬依赖：`index.html` 第 9–10 行的 `app.js` → `workflows.js`（都 `defer`）。`app.js::init()` 用 `typeof restoreExam === 'function'` 兜了一次，但 `#plan-form`、`#diagnostic-form`、`resetWorkspace()`、`assemble({practice_mode:'mock_exam'})` 都是**直接调** `workflows.js` 里的名字；把顺序换掉或把某个函数改名，页面在点这些按钮时才报 `ReferenceError`。
- 提交/闭环的幂等在前端是**参数冻结**，不是重试逻辑：`renderQuestion` 与 `interviewInput` 首次提交前把 body 写进 localStorage 并禁用输入，`trackedCall` 复用同一 `request_id`。改动这些地方让参数发生变化（补个字段、重新计时、允许改答案），后端会 409（`services/memory/receipt.py::verify_receipt`、`LearningStore.replay`），页面表现就是"重试提交"一直红——`tests/test_web_workbench.py::test_saved_submission_replays_only_that_exact_attempt` 与 `web/app.js` 的 `RETRY_NOTE` 描述的是同一件事。
- 计时分两套，别混：普通练习卷的倒计时是 `renderPaper` 里按 `paper.created_at` 的**浏览器时钟**；服务端模考是 `renderExam` 里按 `server_now`/`ends_at` 的相对时钟，且收卡由 `services/exam_sessions/` 决定。`renderExam` 之后 `state.exam` 存在，`renderPaper` 会用它判断"这份卷是不是当前模考会话"，改这个字段名会让交卷后仍显示可提交。
- 不透明感是设计的一部分，不是 bug：`renderPaper` 在下发前已无答案（后端 `item.pop('answer')` 过）、`deferred_feedback` 期间不显讲评、面试 `pending` 阶段后端不返回 `reference_framework/points`。前端不要"顺手"把这些字段显示出来。
- 分数只有后端给了才显示：`renderAnswer` 判 `grading.total_score !== null`，`interviewFeedbackBox` 判 `feedback.total_score === null` 并固定输出"本次不出分数…"。加任何"预估分/通过率"都违背 `docs/web_agent_architecture.md` 与验收口径。
- `#runtime-token` 与 API Key 用途不同（设置页那句 muted 文案就是提醒这两点）：令牌进 `Authorization` 头且只在 `state.token` 内存里；无令牌时后端未设 `KNOWLEDGE_MAP_RUNTIME_TOKEN` 会放行，设了则所有 `/api/v1/web/**`（含子路由 learning/knowledge/exam）都要带头，否则 401 → `api()` 翻成"请先在模型与设置中填写本机运行时令牌。"。
- 音频必须带令牌取：`renderQuestion` 只有在 `state.token` 存在时才显示"加载听力音频"按钮并用 `fetch(..., {Authorization})` + `URL.createObjectURL`，因为没有请求头的 `<audio src>` 会被 401 挡掉。
- `styles.css` 是压缩文件（第 3 行 11740 字符一条），不要手工"顺手格式化"；界面类名与两个 JS 的 `className` 参数一一咬合。
- `start_web.ps1` 会为 `权威资料`→`官方权威资料`、`教资`→`教资原始资料` 创建 Junction（已存在就跳过），只用于让库里记录的相对路径解析到；**不要**通过这两个别名路径写文件，前端改动只碰 `web/` 这四份。
