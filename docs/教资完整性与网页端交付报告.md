# 教资完整性核对与网页端交付报告

日期：2026-10-11（答案冲突首批核对后更新）。依据根目录《应试考证功能设计与技术支撑：以教资和四六级为例》及真实知识库核对，统计由 `审查/audit_ntce_completeness.py` 复现；答案冲突的逐题回卷核对由 `kb_tools/ntce_conflict_reconcile.py` 复现。核对只落回原卷能唯一算出的答案，不改动人工审核状态。

## 核对结论

八层结构与主要数据实体已建成，仍存在内容、细粒度挂载和教研签核缺口。**可以使用研究练习功能，尚不能作为已完整验收的发布知识库。**

八层图谱节点数：L0 2,320；L1 7；L2 38；L3 51；L4 791；L5 586；L6 18,303；L7 11。共 96,785 条边。L7 的 11 项 = 8 项核心资源（理论/法规/面试）+ 3 条无题考点学习指南草稿（`resources/study_guides.jsonl`，审核状态 `needs_fix`、审核人为空、不进正式题池，见 `数据集/教资/resources/README.md`）。系统化概念讲解、例题变式仍可扩展：7 个叶子考点目前整理了 3 个，另 4 个尚无讲解。

严格验收比运行时口径更严：教资 `Q_ANSWER_MISSING` 为 4,487 条，`Q_ANSWER_BINDING_PENDING` 为 2,196 条，`Q_STEM_EMPTY` 为 369 条，`Q_ANALYSIS_INCOMPLETE` 为 4,829 条。它会检查实质文本、答案来源绑定与解析分维，而研究档允许有出处的字母键 / 参考答案。**149 是状态缺失数，不能代替 4,487 的严格答案验收缺口。**各项可在同一题重叠。

首批答案核对落回 22 题后，`Q_ANSWER_MISSING` 与来源冲突各减 22，`Q_ANSWER_BINDING_PENDING` 增 20。这 20 条不是新缺陷，而是同一批题从"没有答案"改记为"答案已回卷落回、待原卷绑定核验"；`Q_STEM_EMPTY`、`Q_ANALYSIS_INCOMPLETE` 一项没减，因为题面与解析分维不会因为答案落回而自动补齐。

两库及补充官方样卷的全量门禁：`structure_errors=0`，`remaining_gaps=130738`，`complete=false`（核对前为 130,762，少的 24 条全部来自这一批：−22 缺答案、−22 来源冲突、+20 待绑定）。状态词表检查两库均 0 违规。这里的 130,738 是多维待补 / 待核定记录，不是缺少 130,738 道题。

- 增加可复跑的教资完整性汇总、38 个学段科目范围明细和 7 个无题叶子考点清单。无题考点已有考纲证据的部分接入问答检索，并提供 [考纲学习索引](教资无题考点学习索引.md)。未找到依据的条目明确留空。
- 补 `paper_spec.json` 与 `tutor_reply.json` 契约；保留原始题库、现有答案、人工审核状态及用户的掌握度公式改动。
- 贯穿组卷、计划和到期复习的学段科目过滤，空题池不扩大范围；修复 memory 向 attribution 传递历史掌握度的接口不一致。
- 增加卷内题目校验、学习者归属校验、刷新恢复与具体考点的掌握度回写。提交按输入指纹回放：同一次作答原样返回，改答案或改参与归因的行为参数在任何学习写入之前返回 `409`，保存失败后的重试只补写页面结果。判定来自库内答案键，模型没有更改判定的权限。
- 网页展示共享材料、CET 阅读原篇和本机源音频；缺图题限制提交。默认 DeepSeek、请求私有 Key、结构化模型回复、来源校验、失败提示和规则降级。
- 交付学习助手、七种练习、计划、学情与复习、面试文字训练、审查及设置页面，附启动脚本、依赖和验收说明。

## 答案冲突分批核对：第一批 `xiaoxue/jiaoyuxinlixue`

选这一批是因为它的隔离题占比最高（36 题里 34 题冲突）且三份原卷答案文件都在本机，逐题可查；**它不是"你实际准备使用的科目"，那一步仍由你定**，工具与门禁可原样换到别的 `学段/科目`。

核对只承认三件同时成立：题干在原卷唯一定位到题号、该题号的答案键是单字母、该字母落在印刷四选项内，并与隔离时保全的候选答案交叉一致。任一件不成立就一行不动，题继续留在隔离态。

| 该批隔离题 | 34 |
| 核对成立并落回答案 | 22 |
| 题干定位不到，留隔离 | 4 |
| 两份抽取不一致（跨题风险未闭合），留隔离 | 6 |

落回后的记录状态：`answer_status=letter_only`、`extra.answer_provenance=letter`、`review.status` 由 `quarantined` 改为 `needs_fix`（隔离态必须与答案可用性同步解除，否则审查会把"有答案但仍隔离"判成结构错误）、`answer_validation_status=not_expert_verified`，`checked_by` 仍为空、`content_verified` 仍为 false、`expert_content_review_needed` 仍挂在待补项里。**落回不产生任何签核，也不产生分数。**

### 拒绝题里还有 7 题是"题面吞掉了邻题"

12 道拒绝题中有 **7** 道的题面带着跨题串入证据（`_summary.json` 的 `refused_with_open_question_boundary`；比拒绝原因 `cross_question_risk_open` 的 6 多 1，因为那 1 题先因五选项多选被拒，串题证据照样登记）。最重的几道不是"答案可疑"，而是**一个选项里装着整段别的题**：`na-p1-jx.q02` 的 E 选项里有 19 道完整 A-D 序列，`na-p1-jx.q04` 的 D 有 7 道，`na-p2-jx.q04` / `na-p2-jx.q05` 的 D 各 3 道，2014 卷的 q08 / q19 / q22 各 1 道。

证据同时给出下一步的分岔：串题文本里露出的邻题编号（`embedded_numbers`）在本卷**没有任何独立题记录**（`boundary_numbers_without_record = 2`，即 `na-p1-jx` 题面里的 77、`na-p2-jx` 题面里的 74——这两份散卷只入库了 4～5 条记录，题号 1～6）。所以这些文本不能剪：剪掉会把库里唯一一份邻题内容删掉。**该批的题面缺陷是收录缺口，不是可清理的冗余**，下一轮要对着原件把漏收的题补成独立记录，再判这题的选项边界。

编号识别按"数字 + 邻题常见开头词"匹配，是下限不是穷举：没识别出编号的串题仍由序列计数暴露；识别出的编号也可能与库内重新编号后的题号不对应，对不上只说明本卷无此记录，是否漏收录仍要回原件确认。串题检测在 `kb_tools/ntce_repair.py` 只有一份口径（`mix_risk_evidence`），核对工具与修复轮共用，测试 `test_the_reconcile_tool_reads_the_same_boundary_rules_as_the_repair_pass` 钉住两处结论一致。

## 后续内容补齐顺序

1. **先核答案与题面。** 首批 22 题已回原卷落回，剩余 **1,018** 题仍隔离；其余批次按同一工具与同一门禁继续（`--scope 学段/科目`）。空题干、缺图、答案绑定与两份抽取不一致也留在严格审查队列里逐题回原件；缺出处不补假答案。首批的 12 道拒绝题另给出一个**题面收录缺口**：7 道的选项里吞着整段邻题、被吞掉的邻题在本卷没有独立记录，下一步是照原件补收录，不是把这些文本剪掉。
2. **再完善细粒度挂载。** 核定 1,331 道题的知识点与能力、3,928 道题的考纲，并处理 201 个知识节点缺考纲绑定。历史 / 物理、综合素质及省考旧科目是挂载缺口较集中的范围；具体数以 JSON 明细为准。

4. **完成量规和审核。** 六份加权量规需教研具名签署；31 条教资先修边未核定，不启用强制前置阻断；发布内容须逐题审核，实测校准依赖真实作答数据。
