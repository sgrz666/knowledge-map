## 本次补充和修复

- 增加可复跑的教资完整性汇总、38 个学段科目范围明细和 7 个无题叶子考点清单。无题考点已有考纲证据的部分接入问答检索，并提供 [考纲学习索引](教资无题考点学习索引.md)。未找到依据的条目明确留空。
- 补 `paper_spec.json` 与 `tutor_reply.json` 契约；保留原始题库、现有答案、人工审核状态及用户的掌握度公式改动。
- 贯穿组卷、计划和到期复习的学段科目过滤，空题池不扩大范围；修复 memory 向 attribution 传递历史掌握度的接口不一致。
- 增加卷内题目校验、学习者归属校验、刷新恢复与具体考点的掌握度回写。提交按输入指纹回放：同一次作答原样返回，改答案或改参与归因的行为参数在任何学习写入之前返回 `409`，保存失败后的重试只补写页面结果。判定来自库内答案键，模型没有更改判定的权限。
- 网页展示共享材料、CET 阅读原篇和本机源音频；缺图题限制提交。默认 DeepSeek、请求私有 Key、结构化模型回复、来源校验、失败提示和规则降级。
- 交付学习助手、七种练习、计划、学情与复习、面试文字训练、审查及设置页面，附启动脚本、依赖和验收说明。

## 后续内容补齐顺序

1. **先核答案与题面。** 从严格审查队列按题号回原件核对 1,040 个冲突、答案绑定、缺图和空题干；缺出处不补假答案。
2. **再完善细粒度挂载。** 核定 1,331 道题的知识点与能力、3,928 道题的考纲，并处理 201 个知识节点缺考纲绑定。历史 / 物理、综合素质及省考旧科目是挂载缺口较集中的范围；具体数以 JSON 明细为准。
3. **补七个叶子考点的练习。** 初中历史、生物、物理、信息技术及高中物理、音乐的“学情分析与教材分析”；初中体育“教学资源与板书设计”。应使用有来源的题目或明确标记的新编草稿，不能将父节点无题视作全部命题缺口。
4. **完成量规和审核。** 六份加权量规需教研具名签署；31 条教资先修边未核定，不启用强制前置阻断；发布内容须逐题审核，实测校准依赖真实作答数据。
5. **补媒体和完整模考。** 逐题绑定原图，核对听力分组切片，完善 CET 逐节作答 / 收卡状态与媒体控制。当前网页不声称实现全真考场时序。

## 使用与验证

按 [网页使用说明](web_agent_usage.md) 启动，在 `http://127.0.0.1:8000/` 的“模型与设置”填写 DeepSeek Key。无 Key 可先完整走一次“练习 → 提交 → 学情 → 复习 / 计划”。自动化与浏览器验证结果记录在 [验收记录](web_agent_verification.md)。

机器可读明细：`审查/教资完整性核对.json`。全量严格审查：`.local_state/web_audit_final.json` 与同目录 `知识库待补队列.jsonl`。这些报告是运行快照，修改题库后请重新执行审查命令。
