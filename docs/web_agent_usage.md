# 知序网页端：安装、使用与验收

这是运行在本机的教资 / 四六级智能备考工作台。沿用本库的知识门面、八个能力 Agent、可信门禁和 SQLite 学习记录。默认接 DeepSeek，无 Key 时也能使用真实题库练习、规则检索、计划、学情和面试文字反馈。

## 启动

需要 Python 3.11 或更高版本；本轮在 Python 3.13 上验证。PowerShell 中运行：

```powershell
cd D:\codeplus\knowledge_map
python -m pip install -r requirements.txt
.\start_web.ps1
```

也可一次安装并启动：`.\start_web.ps1 -Install`。脚本会在缺失时为现存的真实资料目录建立 `权威资料` / `教资` 本机 Junction。网页地址：**http://127.0.0.1:8000/**。保持终端运行，按 Ctrl+C 停止；8000 被占用时用 `.\start_web.ps1 -Port 8001`。

若 PowerShell 的脚本策略阻止启动，可使用相同的 Python 入口：

```powershell
python -m uvicorn services.app:app --host 127.0.0.1 --port 8000
```

首次加载会读取本地题库和图谱；第一次问答还会建立词法卡片索引，可能需要几十秒。当前运行不要求 Node.js 或 Chroma。Chroma 为可选检索扩展，没有安装时界面会如实显示词法检索。

## 配置 DeepSeek

打开左下角“模型与设置”，填写：

| 设置 | 默认值 / 说明 |
| --- | --- |
| Base URL | `https://api.deepseek.com`，也支持服务商的 HTTPS OpenAI 兼容 Base URL |
| 模型 | `deepseek-flash`，可替换为自己账户有权限的模型名 |
| API Key | 在 DeepSeek 平台创建的 Key |
| 学习者标识 | 默认 `local-learner`；换一个标识可建立独立学习记录 |
| 内容档位 | 默认“研究练习”；当前无具名签署题，“签署内容”会返回空池 |
| 本机令牌 | 默认无需填写；只在后端设置了 `KNOWLEDGE_MAP_RUNTIME_TOKEN` 时填写 |

先“应用配置”，再“测试连接”。成功后问答会显示“模型已参与”；失败会显示实际错误并保留规则检索结果。默认 URL 和模型名依据 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/)（2026-10-11 查询），后续服务商改名时可在网页修改。

Key 和本机令牌仅保存在当前页面内存，刷新后重新填写。它们不写入 localStorage、学习数据库、全局模型客户端或环境变量；非敏感偏好可以保存在浏览器。主动请求模型时，Key 经本机后端转发到所填模型服务，相关题目、条款和近期对话作为上下文发送。**本轮没有你的真实 Key，线上 DeepSeek 连通性需要你在这里实测。**

## 日常使用

1. 顶部选择考试、学段和科目。教资支持小学、幼儿园、中学公共科目、初高中学科和中小学面试任务。范围切换会清空当前页面的对话和任务，后端已保存记录仍在。
2. 在“学习助手”提问，例如“什么是因材施教”。右侧展开题目 / 官方条款及原文定位。未配置模型时展示检索依据；配置后模型解释本次真实证据，引用越界的回复会被拒绝。
3. 在“练习与模考”选择七种模式、题量和具体考点。真实题池不足会少发题或返回空卷。客观题提交后由库内答案键核对；主观题提供练习反馈。题干疑似依赖配图且当前没有图像时，仅供查看，不能提交。材料分析与 CET 阅读会显示关联全文；听力原始文件存在时可播放整段音频。
4. 提交后查看讲评、错因和复习间隔；“向助手追问”携带该题证据继续解释。“反馈内容问题”将描述送入本机教研待复核队列。一次练习里的同题只能提交一次，HTTP 重试不会重复更新画像；重新组卷形成新练习。
5. 打开“学情与复习”查看真实记录、薄弱项和到期题，点击“复习到期题”。刷新会恢复该学习者最近一份匹配范围的练习卷及这一次的提交状态。
6. 在“学习计划”填备考天数、每天分钟数，生成当前范围计划；点击每项“开始任务”进入对应考点练习或复习。计划可导出 JSON。
7. “面试练习”支持教案、试讲转写和结构化作答。教案 / 转写采用现有规则反馈，结构化作答可接 DeepSeek。浏览器支持语音识别时可主动录入，否则粘贴文字。文字无法反映仪态、发音或视频表现。
8. “知识库审查”展示实时统计、八层节点、逐学段科目缺口，可导出 JSON。完整原始审查见 `审查/教资完整性核对.json`。

## 可复跑验收

先安装测试依赖并运行：

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
python 审查/audit_ntce_completeness.py
python 审查/状态词表检查.py 数据集/教资
python 审查/状态词表检查.py 数据集/四六级
python 审查/validate_kb.py --output .local_state/web_audit_final.json
```

完整性审查最后一条在仍有内容缺口时退出码为 1；分别看 `structure_errors` 和 `remaining_gaps`，不能把结构无错当作内容已审核。自动化网页用例在 `tests/test_web_workbench.py`，测试学习者使用 `web-test-*` 等独立标识。

浏览器验收建议：先保持 Key 空白，选“小学 / 综合素质”，提问、生成 5 题、提交一道选择题、看学情、刷新确认提交恢复，再生成 2 天计划并启动任务；切换科目检查任务未混用；试贴一份教案 / 转写文本；用手机宽度检查导航和题目；最后填真实 Key 点“测试连接”，确认问答显示模型参与和引用。切换“签署内容”应返回无可用内容，不调用模型。

## 数据和边界

个人学习数据在 `.local_state/`，含 memory、session、复核队列和 `workbench.sqlite3`。备份整个目录即可保留进度；默认单进程启动。每个考点的掌握度 / 错题更新与事件回执在 memory 数据库内事务提交，提交结果保存失败后重试不会重复更新已处理考点。两份数据库仍不是一个跨库事务：异常时需要重试原提交以补齐页面结果；多个 worker 的完整协调尚未实现。

当前无人工签署题和实测 IRT 校准，六份教资加权量规待签署，因此不能提供权威自动评分、官方报告分或通过概率。模考页面使用整卷计时与实际组卷结构，尚未实现 CET 的逐节收卡 / 强制音频切片；未经核对的时间切片不用于强制播放。图示题识别是保守文本规则，仍需人工检查题面抽取质量。学习反馈反映研究档题库及服务规则，答案和挂载状态请结合来源核查。

默认只监听 `127.0.0.1`。这是本机使用交付；未上传题库、未建立公网网站。面向多人或公网部署需另补账户认证、用户权限、限流和 HTTPS。
