# 网页端备考智能体设计

依据根目录功能方案和现有 Agent 架构，扩展现有 FastAPI 服务，提供本机网页工作台，默认 DeepSeek。Python 知识门面仍是唯一数据入口；470MB 本地资料和 SQLite 学习记录随本机后端使用，网页无需 Node 构建，也不把题库上传到第三方托管平台。

## 用户流程

1. 启动服务，选择教资学段、科目或 CET-4/6；默认研究练习档。
2. 在设置里填写 HTTPS Base URL、模型名和 API Key；Key 仅在当前页面内存中，逐请求传给后端，不进 localStorage、SQLite、日志或全局环境变量。可测试连通性、清空 Key。默认参数来自 DeepSeek 官方文档 https://api-docs.deepseek.com/ ，2026-10-11 查询。
3. 问答先检索本地题卡、图谱和可引用条款，模型只解释真实证据；回复携带来源、模型参与状态和调用错误。无 Key 可使用规则功能。
4. 七种练习和模考使用真实题池；提交后库内答案键核对、诊断、错因归因、间隔复习、画像回写。主观题仅在量规签署后出分，否则提供反馈。
5. 计划按选定学段、科目生成；画像、错题本和到期复习使用已有持久化记录。面试支持教案与试讲文字转写分析，浏览器语音输入作为可选输入方式，未支持时可手动输入。
6. 完整性面板逐学段科目显示可练题数、答案缺失、冲突、知识点及考纲挂载缺口、签署情况和八层图谱分布；报告可导出，问题可提交纠错。

## 改动边界

- services/web：请求配置、工作台门面、可持久化练习提交、路由。
- web：独立 HTML/CSS/JS，米白纸感与深绿色的备考书桌风格，移动端自适应，所有题面和模型文字通过 textContent 渲染。
- services/knowledge：补充材料读取与完整性汇总；不制造知识、答案或审核状态。
- services/planner、practice：学段科目筛选贯穿每日练习与计划，空池不退到其它学段。
- schemas：补 paper_spec 和模型回复契约；审查 CLI 输出完整性报告，剩余缺口持续可见。
- 修复现有 memory 调用 attribution 的 persisted_mastery 接口不一致，保留工作区已改的掌握度公式。

## 验证

新增 API 回归覆盖配置隔离、Key 不回显、模型失败、引用越界、研究/发布门禁、学段过滤、答案提交与幂等、材料展示和拒绝跨卷提交。完整跑 tests、知识库结构及状态门禁，并在真实浏览器测试配置、问答、练习、提交、计划、面试和移动布局。没有用户真实 Key，不声称验证过 DeepSeek 线上调用。

## 已知边界

目前无人工签署题、无实测校准、未签署量规，published 空池。语音输入依赖浏览器支持，无法据文字评价仪态、发音和视频表现。教资规格无逐节时序，仅做整卷计时；缺少官方换算参数时不预测通过率。面向个人本机使用，默认监听 127.0.0.1。
