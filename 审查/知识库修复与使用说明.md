# 四六级与教资知识库修复、验收与使用

本次修复保留两库的全部题目，修复生成器和已生成数据，补上知识点、能力、具体考试要求、原始资料及审核状态之间的引用。最新全量结果在 `知识库验收结果.json`，逐条待补任务在 `知识库待补队列.jsonl`；`修复前基线.json` 和旧审查报告用于比较修复前状态。

## 数据入口

| 内容 | 仓库内路径 | 使用方式 |
| --- | --- | --- |
| 四六级题目 | `数据集/四六级/questions/cet4/`、`cet6/` | 每行一题，按 `question_id`、`knowledge_node_ids` 或题型筛选 |
| 四六级语篇 | `数据集/四六级/passages/reading.jsonl` | 用题目 `extra.passage_id` 连接 `resource_id`，选词填空的共享词库也在语篇中 |
| 四六级听力文字稿 | `数据集/四六级/listening/transcripts.jsonl` | 核对来源卷别与题组；完成原题身份匹配的记录通过 `extra.listening_transcript_ids` 关联 |
| 四六级本体和量规 | `数据集/四六级/ontology/` | 解析知识点、能力、考试要求和 `rubric_id`，量规原始分与报道分分别处理 |
| 写作、翻译、词汇资源 | `数据集/四六级/writing/`、`translation/`、`vocabulary/` | 学习资源的 ID 与题目 ID 分开管理；写译资源含任务要求和参考文本 |
| 教资题目与材料 | `教资KB/questions/`、`materials/` | 按学段、学科读取，使用 `material_id` 连接共享材料 |
| 教资图谱与卡片 | `教资KB/graph/`、`outline/`、`cards/` | 沿包含关系遍历模块到知识点；Markdown 卡片可直接预览 |
| 官方来源 | `权威资料/catalog.json`、`requirements.jsonl` | 以 `standard_id` 和 `requirement_id` 连接原文、版本、URL、校验值和定位 |
| 官方样题与样卷补充 | `补充资料/教资官方样题/`、`补充资料/四六级官方样题/` | 单列官方大纲样题、样卷与评分作答，原件图像可查看；低分评分样例不作范文 |
| 幼儿保教参考解答 | `补充资料/教资参考解答/` | 官方指南支持的原创练习草稿，精确连接原题；非考试官方答案，待专家审核 |
| 复核队列 | `教资KB/review/`、`审查/知识库待补队列.jsonl` | 按问题 ID、规则与来源定位处理缺口，完成后重新运行验收 |

JSONL 必须按物理行读取，例如 `for line in path.open(encoding='utf-8-sig')`；不要用整文件 `splitlines()` 切分，题目字符串可能含 Unicode 行分隔符。

```python
import json
from pathlib import Path

root = Path(r"D:\codeplus\knowledge_map")
selected = []
for path in (root / "数据集/四六级/questions/cet4").glob("*.jsonl"):
    with path.open(encoding="utf-8-sig") as stream:
        for line in stream:
            if line.strip():
                question = json.loads(line)
                if "cet4.read.cloze" in question.get("knowledge_node_ids", []):
                    selected.append(question)
print(len(selected))
print(selected[0]["question_id"] if selected else "暂无匹配题")
```

单元测试通过证明修复规则的行为符合回归样例。官方资料校验检查归档文件、条目定位和官方量规分值。全量验收在所有检查项都齐备时才返回 0；存在结构错误或待补内容时返回 1，并保存完整问题队列。退出码 1 不能解释为“可以忽略的成功”。

`structure_errors` 是引用或数据结构错误数，`remaining_gaps` 是待补事项数，同一题可能有多个事项。这两个数字都不是不合格题数。题目完整率和资源完整率分别统计，题目的统计不替代图谱及官方来源统计。

补充四六级官方样卷的标准题目格式也由统一验收器单列检查，其题数不混入原5294题的净修复统计。教资官方样题的单题、题组和完整章节分开保存；不能将题组计为一条已经拆分完成的题目。官方样题与原题题号相同不足以回填，必须核对完整题干、选项及语篇。

重新生成库之前请参照各库 README 的顺序；恢复原始答案、迁移 schema、补全来源和重建统计属于不同步骤。生成器保留扩展字段与已有复核信息，待审材料仍须从问题队列继续处理。

## 内容状态的含义

`source.files` 提供原题、答案、解析等文件的独立角色及定位。文件存在、哈希一致、原文定位成功和专家内容审核是不同状态。`source.verified` 不代表题目已经通过学科专家审核。

题目ID、ID末尾数字和库内`paper_order`是历史标识，不一定等于原卷题号。核对或显示原题序号时，应使用有原文依据的`extra.source_question_number`及来源定位；题干、全部选项和语篇身份不一致时，不能只凭编号回填答案或替换题目。

`exam_requirement_ids` 对应具体条款。词项自动对齐或从官方范围拆出的细知识点保留证据和待复核状态；模块分组节点 `assessable=false` 不参与题目考点打标。先修建议不会因大纲排列顺序自动成为已核定先修关系。

缺失答案保留空值，来源冲突的候选答案保留历史记录并退出有效判分字段。解析中没有原文证据的段落保留空值。难度尚未校准的题目不会填入伪造数值。量规建议稿可以帮助组织练习反馈，其状态与官方评分描述分别保存。

用户已确认没有现成教研审核或作答数据，本次允许保留“待审核、待标定”。汇总报告单列这些状态，完整性门禁仍显示尚未完成专家审核与标定；这一约定不豁免缺失题干、选项、答案、解析或原文材料的修复。

听力整套音频与题组起止时间分别管理；只找到整套文件不代表每道题已经完成音频定位。

引用理论原文时需要核对定位约定。幼儿参考解答统一使用LF物理行，并保存区间`context_sha256`；Word中的垂直制表与Unicode分隔符不能按文件换行计数。题目或资源的来源文件若记录了SHA-256，统一验收会检查实际哈希，不能只用“文件存在”证明未变化。

CSE 现行版本为 GF 0018—2024，2018 版保留历史记录。已经取得官方 2024 能力描述数据，但未取得整本出版 PDF，也未取得 CET 分数与 CSE 等级的正式对接依据，不能直接把四级、六级设为 CSE 的某两个等级。

知识库包含题目和静态映射；用户作答、掌握度、诊断、推荐与学习计划属于应用运行时数据，需由使用这套库的应用保存和更新。
