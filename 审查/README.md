# 审查 — 质量审计与门禁工具层

本目录汇集了全库的数据质量门禁脚本、形式审查工具以及历次修复审查报告。

## 核心脚本与文档
- **alidate_kb.py**：统一知识库全量质量门禁（检查悬空引用、假校准、答案冲突等）。
- **知识库形式审查.py**：全量扫描四六级与教资题库的拓扑连接、覆盖率与 JSON 格式。
- **四六级与教资修复验收报告.md**：记录修复前后的核心指标对比与全库待补队列。
- **四六级与教资知识库符合性审查.md**：首次审查时的基线审计证据。
- **知识库修复与使用说明.md**：修复后知识库的使用方式与复跑指南。

## 子目录说明
- **atch/**：分批次审查与修复辅助脚本。
- **harness_batches/**：大模型批处理测试样例集。
- **_work/**：审查中间临时导出的数据与脚本缓存。
- **验证日志/**：历次全量验证的运行日志。
