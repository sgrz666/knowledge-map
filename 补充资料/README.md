# 补充资料/ —— 官方样题与参考解答的抽取产物层；由 kb_tools 与 审查/ 下的构建脚本生成，被数据集/教资（样题匹配、指南引用）与四六级库审查消费

本目录是主库之外的独立补充层：`数据集/四六级/questions/` 的 5,632 条题源仍是真题文件，官方样卷未并入主库，`审查/validate_kb.py` 以独立 base_paths（仓库根 + `补充资料/四六级官方样题` + `权威资料`）按同一题目契约单独校验并单列计数；`数据集/教资/questions/` 有 53 处 `source.files[].path` 直接写 `补充资料/教资官方样题/preschool_guideline.2012.txt`、16 条题目经 `extra.source_repairs[].draft_file` 回指 `补充资料/教资参考解答/reference_drafts.jsonl`（均为现算）。这里的路径全部写真实目录名 `补充资料/…`，不走符号链接；但样题记录内部的 locator 前缀 `权威资料/` 依赖工作区根的 `权威资料 -> 官方权威资料` 链接。抽取产物（含 40,879,791 字节的 source_pages.json）可由脚本重建；答题卡等扫描件原件只留原图与哈希，不入库检索。

## 口径

样题不是某年月实考真题，题目/解答记录一律 `review.status=pending_expert_review`、难度为空；恢复补丁要求完整题干+全部选项一致且官方答案真实存在，主库从未被这些脚本直接改写。扫描件（如四六级八张答题卡 194–201 页、指南 DOC 中的图形）不产出可信文字就不标完整提取，只保留原图与哈希，这就是"原件不入库、但可溯源"的边界。
